# GIMATech Phase 1 Storefront

## Goal
Build the first polished, responsive GIMATech homepage for Ghanaian technology shoppers. This phase uses realistic demo inventory only and does not add authentication, payments, orders, or backend services.

## What will be built
- Original lime-green, charcoal, white, and light-gray brand system aligned with the GIMATech logo direction.
- Sticky desktop navigation and mobile menu with search, account, wishlist, and cart entry points.
- Technology-led first section with a professional product image and clear shopping actions.
- Trust benefits covering product quality, secure shopping, delivery, and customer support.
- Expandable category data and a clean category browser for the 16 requested technology groups.
- Reusable product cards populated with clearly labeled sample products and Ghana Cedi prices.
- Featured Products and mobile-scrollable Trending in Tech sections.
- Upgrade Your Setup promotion, Why GIMATech, newsletter signup presentation, footer, and configurable WhatsApp support button.
- Clear demo-data notices so inventory, prices, stock, checkout, and availability are not presented as live.

## Visual direction
- Predominantly white/off-white surfaces with charcoal structure and restrained lime accents.
- Amber reserved for offers; red reserved for unavailable or warning states.
- Product photography carries the visual interest instead of gradients or decorative effects.
- Compact rounded cards, crisp typography, subtle shadows, generous spacing, and minimal motion.
- Shopping flow follows the reference’s clarity while all branding, composition, copy, imagery, and components remain original.

## Technical approach
- Keep TanStack Start’s route structure and React/TypeScript/Tailwind v4 foundation.
- Add modular types, demo data, layout, navigation, category, product, marketing, and footer components.
- Use semantic design tokens in the global stylesheet and reusable button variants.
- Generate and bundle cohesive technology product imagery locally.
- Add unique homepage metadata and accessible semantic structure.
- Validate the finished page at desktop and key mobile widths, including navigation behavior and horizontal overflow.

## Scope boundary
Phase 2 shop/search/filter/product-detail pages, Phase 3 cart/checkout functionality, and all database, C++, MySQL, authentication, payment, order, inventory, and admin work remain deferred until requested.
